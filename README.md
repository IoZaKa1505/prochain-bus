# Prochain bus

Horaires des bus TEC dans le Hainaut : prochains passages par arrêt, ligne et direction.
App web installable sur iPhone, qui fonctionne hors ligne.

Ouvrir : https://iozaka1505.github.io/prochain-bus/

Horaires théoriques issus des données ouvertes TEC (pas de temps réel).
Mise à jour des horaires : `python3 build_data.py <dossier_gtfs_decompresse> data.json`
